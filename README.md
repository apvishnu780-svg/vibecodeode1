# vibecodeode1

A simple starter project for building and experimenting with web front-end code.

## Included files

- `index.html` – page structure
- `styles.css` – layout and styling
- `script.js` – small interactive behavior
- `.gitignore` – common ignore rules

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
